# Cascade · Partner Cabinet UI Kit

Referral cabinet: link sharing, missed-earnings widget (when referrer's tier is lower than referral's purchase), bonus stats, list of invited users with statuses.

## Files
- `index.html` — composition.
- `App.jsx` — page layout.
- `RefLinkCard.jsx` — copyable link + "grey" inactive state.
- `MissedEarnings.jsx` — running total of cut-off bonuses.
- `BonusStats.jsx` — total earned / cells filled / 5-friends progress.
- `InvitesTable.jsx` — list of invited users (id, level, status).

## Note
This kit reuses the Sidebar from the Dashboard kit by including its script file.
